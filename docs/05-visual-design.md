# 05 · 视觉规范与动效

当前实现是**深色赛博朋克霓虹**：把「终端遥测」当作视觉语言——实时 HEX 流、SEQ / RSSI / MAC 都是真数据，不贴假的科技感装饰。`docs/design-history/` 里那套暖白底方案是更早期的设计，与本实现无关。

## 色板

| 角色 | 色值 |
|---|---|
| 画布 | `#05060F` / 顶部 `#0A0F22` / 底部 `#02030A` |
| 表面 | `#0B1020` / `#101A33` / 描边 `#1D2C4E` |
| 主青 | `#00F0FF` |
| 品红 | `#FF2E97` |
| 紫 / 绿 / 琥珀 | `#8B5CF6` / `#39FF88` / `#FFB020` |
| 文字 | `#E9F6FF` / `#8194BC` / `#4A5B7F` |

**数据语义色**：下降 / 达成 = 荧光绿，上升 = 琥珀（只表示体重变化方向，不沿用股市红涨绿跌）。
**成员主题色**：每个成员可指定，驱动网格、扫描线、卡片描边，便于多人切换时快速辨认。

### BMI 等级色（独立语义，优先级高于主题色）

| 等级 | 色值 |
|---|---|
| 偏瘦 | `#38BDF8` 冷蓝 |
| 正常 | `#39FF88` 荧光绿 |
| 超重 | `#FFB020` 琥珀 |
| 肥胖 | `#FF2E97` 品红 |
| 待评估（无身高） | `#00F0FF` 主青 |

等级色只驱动测量页中央仪表主弧 / 刻度 / 光点 / 数字光晕与 BMI 分级卡；网格、扫描线、卡片描边仍用成员主题色，保证整体观感不被打散。分级规则见 [04-metrics-and-database.md](04-metrics-and-database.md)。

## 字体

中文用系统默认无衬线；数字 / hex / 标签用等宽字体，形成终端读数质感。定义见 `ui/theme/Type.kt`。

## 动效清单

| 组件 | 效果 |
|---|---|
| `CyberGridBackground` | 透视网格 + 7s 循环扫描线拖尾 + 双色呼吸辉光 |
| `NeonRingGauge` | 72 格刻度环、渐变进度弧、发光复描、旋转光点、`spring` 数字滚动、锁定状态徽章；v1.1 起主色按 BMI 等级切换 |
| `ScanPulse` | 三层同心波纹错峰扩散，由实时帧驱动 |
| `NeonLineChart` | 曲线从底部升起（`Animatable`）、三次描边模拟辉光、目标虚线、末点呼吸脉冲 |
| `HexStream` | 实时广播帧 hex + 闪烁光标 |
| `UserAvatar` | 激活成员的旋转弧 |
| `HistoryScreen` | 列表项 fade + slide 入场 |
| 页面切换 | `AnimatedContent` 淡入淡出 |
| `LedDot` / `SignalBars` | 扫描状态呼吸灯、RSSI 四级信号条 |

全部用 Compose 动画 API 与 Canvas 自绘实现，**没有 Lottie / 图表库 / 图标库 / 位图资源**。

## 四屏

1. **测量**：成员切换条 + 主仪表（BMI 等级联动）+ 实时链路状态（RSSI / HEX / MAC / 暂停）+ BMI 分级卡 + 三指标卡 + 广播遥测诊断。
2. **趋势**：7D / 30D / 365D 切换 + 发光折线 + 区间统计 + 目标进度说明。
3. **档案**：次数 / 最新 / 平均 + 可点开详情的测量记录流（含 SEQ / RSSI / MAC）+ 空态。
4. **成员**：多人卡片（增删改、切换、主题色、性别 / 身高 / 生日 / 目标体重）+ 显示单位（kg / 斤 / lb）+ 设备与协议信息。
