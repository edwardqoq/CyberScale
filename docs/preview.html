04 / 协议与数据约束 PROTOCOL FACTS

项说明
广播帧manufacturer AD type 0xFF，公司 ID 0x20CA（小端 CA 20），共 21 字节
实测样例CA 20 0B 12 12 12 12 01 05 25 1D 74 03 E8 E1 AA BB CC DD EE FF → 7540÷100 = 75.40 kg
properties bit0最终值 / 锁定标志。0x05 最终 2 位小数、0x04 实时 2 位小数
落库规则实时帧只驱动 UI；最终帧 2.5s 滑窗、同 seq ≥2 条且极差 ≤0.05kg 才写一条，20s 同值兜底去重
多人归属记录归属当前激活成员；保存后 Snackbar「改归属」可改挂到别的成员
本地存储Room / SQLite cyberscale.db，users 与 records 一对多 + 外键级联；无账号、无云、无网络
协议里没有体脂 / 水分 / 肌肉 / 基础代谢 / 骨量 / 内脏脂肪 / 温度 / 电量 —— 不展示、不估算、不填充假值
注意：本页是设计意图的浏览器预览（CSS/SVG 模拟），不是真机截图；实际界面以 Android 工程运行效果为准。页面中的体重、次数、进度均为示例数据。
