05四屏逐屏改造清单

Screen-by-Screen Implementation Checklist

5.1　动态 · 今日概览

目标　一屏看清「现在多重、和上次比如何、离目标多远」。

契约　上表 fragment_dynamic 全部 ID 必须保留，否则 DynamicFragment 空指针崩溃。

  1. 移除位图表盘 home_biaopan_bg 与指针 home_zhizhen_icon；pointer / valueLayout 可保留 ID 但设 visibility=gone，不要删节点。
  2. 新增 RingProgressView（140dp、9dp 描边、#34D399、圆角端点），叠在 valueText / valueUnit / timeText 之后作为背景层；环心数字 40sp Bold，单位 11sp。
  3. Hero 底部条放 BMI / 体脂 / 肌肉三项：BMI 新算，后两项无数据 → 显示「--」，不要留空。
  4. 指标双卡换 bg_card_white_18：距上次（绿 #10B981 或琥珀 #F59E0B）、30 天最佳（#014DB2）；bestWeightValue 现为差值，设计稿要绝对值，需改取值。
  5. 目标进度：先修算法（见第 3 节），再换 bg_progress_track / bg_progress_fill；文案「已完成 x%」「还差 x kg」。
  6. 身体成分报告卡：三行在无数据时统一显示「-- · 该秤型不支持」或整卡收起；reportEntry 点击仍跳 ReportActivity。
  7. indexGrid 由代码动态生成 6 格；无数据字段继续显示「--」，仅改 cell 背景与字号色值。

5.2　趋势 · 数据曲线

目标　把「变化」可视化，让用户看到趋势方向而非孤立数字。

契约　weightChart / fatChart / trendWeightValue / trendFatValue / trendWeightHint / periodWeek / periodMonth / periodYear 全部保留。

  1. 周/月/年 改用 bg_segment_track + bg_segment_active，激活项白底 + 微投影；三个 OnClickListener 逻辑不变。
  2. 体重折线复用 LineChartView：扩展面积渐变（LinearGradient shader）、7 个数据点、末点薄荷绿高亮 + 虚线引导、日期轴标签。外裹 bg_card_white 图表卡。
  3. 体脂柱状图：因 fat 全为 0，改为占位态卡「体脂数据需支持 GATT 的秤型」，或整卡 GONE；不要保留假柱子。fatChart / trendFatValue 仍需在布局中存在（可设 GONE）。
  4. 新增「本周洞察」卡（bg_insight_green）：按近 7 天首末差值生成文案，数据 < 2 条时隐藏。
  5. 趋势页「较上周 -1.2 kg」「范围 61.8 - 63.6 kg」均由 db.list() 计算，不写死。

5.3　历史 · 测量记录

目标　从空白变成可扫读的记录流，并给出统计口径。

契约　historyList / emptyView / totalCount / latestWeight / avgWeight，以及 item_history 内 7 个 ID。

  1. 统计概览已有三个 TextView，改成三等分白卡 + 24sp 数字层级；数值来源不变。
  2. 原按日期分组的列表结构可保留；新增月份切换行「2026 年 11 月 / 共 x 条记录」。
  3. 记录行换 bg_record_row（14dp 圆角 / #F6F9FC），日期 11sp、体重 16sp Bold、涨跌 11sp；涨跌色统一为 #10B981 / #F59E0B（替换现有 record_up / record_dwon 色值）。
  4. fatText / fatCompare 无数据 → setVisibility(GONE)，不要显示「--%」占位行。
  5. 新增「数据小贴士」卡（bg_tip_blue）：「固定每天同一时间测量，趋势更准确」。
  6. emptyView 保留并改造为真正的空态（见第 8 节，设计侧可补稿）。

5.4　我的 · 个人中心

目标　把大色块改成有信息量的档案 + 目标 + 设备入口。

契约　nickname / roleInfo 与 9 个 btn* 全部保留，OnClickListener 逻辑不变。

  1. 顶部改 bg_hero_gradient 个人信息卡（128dp）：头像（可沿用 default_head_image）、昵称 18sp Bold、副文案「已坚持记录 x 天 · 连续 x 天」需新增统计逻辑。
  2. 新增体重目标卡，与动态页共用 bg_progress_track / bg_progress_fill，保证两处进度算法一致。
  3. 资料列表改 bg_card_white：5 行（昵称/性别/身高/出生年月/体重目标），44dp 行高；btnUnit / btnFeedback / btnAbout 建议收进第二组列表，不要删。
  4. 我的设备卡：电量 82% → 「广播监听中 · 无需配对」，可接 BleManager 扫描状态做呼吸点；「管理」入口沿用 btnDevice。
