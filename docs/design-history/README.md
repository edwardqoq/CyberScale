# design-history/ — 初版 UI 设计方案（历史资料）

> ⚠️ **这里不是当前 NEON//SCALE 的界面。** 当前实现是深色赛博朋克霓虹风格；本目录是项目**更早一阶段**针对旧 base 版 App 做的界面优化方案（暖白底、深蓝渐变、薄荷绿数据色）。两套设计相互独立，请勿把这里的截图当作本仓库代码的运行效果。

保留目的是**记录设计决策的演进**：从「清爽的数据工具」到「以广播遥测为视觉语言的赛博朋克仪表」，为什么改、改了哪些信息层级，有据可查。当前实现的视觉规范见 [../05-visual-design.md](../05-visual-design.md)，四屏交互预览见 [../preview.html](../preview.html)。

2. **已做脱敏**：入仓副本中的本机用户名、本机 SDK / 工程绝对路径、抓包得到的真实设备 MAC 均已替换为占位符或示例值；`work/设计文档/`、`work/重设计稿/` 下的原始交付件保留在本地，未做修改。
